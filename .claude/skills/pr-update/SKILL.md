# PR Update

Create or update the current branch's PR. Title and body are generated by
`claude -p` invoked from inside the command — the agent running this skill does
**not** compose them. `pr-commit` runs this same step as its last one; this is
that step alone, for a branch already committed and pushed.

## Steps

### 1. Run the command

It reads the branch's commits and diff vs `origin/main` (falling back to
`origin/master`), generates a conventional-commit title and body, then creates
a new PR or edits the existing one. It prints the PR URL.

```bash
go run ./scripts/cmd/pr-update
```

### 2. Post-PR follow-up (when an issue was referenced)

If project docs contain a `**Issue Reference**: [#<n>](...)` link relevant to this branch, also:

1. Check the issue body for an existing `**Related PR**` link.
2. If missing, `gh issue edit <n> --body-file …` to add `**Related PR**: #<pr_number>: <pr_title>`.
3. If present, refresh the existing PR link with the current title.
4. Apply appropriate labels (e.g., `in-progress`, `has-pr`) via `gh issue edit --add-label`.

## Rules

- It writes under `tmp/commit/`, so the generated body survives the run.
- Its `gh pr view` probe decides create-vs-edit — do not pre-check from SKILL.md.
- It outputs the PR URL — report that back to the user.
