One-line: the system's text field — uppercase label, square border, no fill, no radius.

```jsx
<Input label="Email" placeholder="you@company.com" type="email" />
```

- Focus darkens the border to black; there is no focus glow or ring colour.
- Pair with a full-width `Button` directly beneath, flush, for contact forms.
- Intentional addition: the guideline defines no form controls, but contact capture is required for landing pages.
