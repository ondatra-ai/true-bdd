# docs/for_further/

Agreed designs for work not started yet — one Markdown file per idea.

Tracked, and deliberately outside the doc universe: nothing under `documents:` or
`paths:` in `true-bdd/true-bdd.yaml` names this directory, so `sync-doc-universe`
does not audit it.

**Each file carries its own decision log**, so the design can be picked up without
the conversation that produced it. Open with a status line naming what was agreed
and when, and whether anything has started — see `observability.md`.

This is for designs. Actionable work goes to the ClickUp list named in `CLAUDE.md`;
a note here that has become a task should move there rather than being worked from
this directory.
