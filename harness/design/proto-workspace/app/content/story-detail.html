60.2 — Summary For Shared Docs

Planned Created 1/2 Not recorded

As a Claude User,
I want Claude to give me a short summary of a shared Google Doc when I ask for one,
so that I can decide whether the document needs my attention without reading it in full.

Acceptance criteria

AC-1

Claude must display a summary of 150 words or fewer in the conversation when the Claude User asks for a summary of a shared Google Doc.

  • Givena Google Doc with at least 500 words of body text is shared with the Claude User's account
  • Whenthe Claude User asks Claude to summarize the document
  • ThenClaude displays a summary of 150 words or fewer in the conversation
  • Andthe summary names the document title
AC-2

Claude must display the message 'This document is not shared with your account' when the Claude User asks for a summary of a document they cannot access.

  • Givena Google Doc exists that is not shared with the Claude User's account
  • Whenthe Claude User asks Claude to summarize that document
  • ThenClaude displays the message 'This document is not shared with your account'
  • ButClaude does not display any content from the document
