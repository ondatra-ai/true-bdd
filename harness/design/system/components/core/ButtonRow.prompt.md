One-line: wraps two or more Buttons into the guideline's flush horizontal row (no gap, shared borders).

```jsx
<ButtonRow>
  <Button variant="primary">See How We Build for Change</Button>
  <Button variant="secondary">Start the conversation</Button>
</ButtonRow>
```

- `full` makes the row span its container with equal-width buttons — the standard hero treatment.
- Never add `gap`; the flush seam is the point.
